## ForgePad 1.0.2

Исправление «Access to the path … is denied» при добавлении звуков.

### Что изменилось

- **Папка данных выбирается по факту возможности записи.** Программа пробует
  `%LOCALAPPDATA%\ForgePad`, затем `Documents\ForgePad`, затем временную папку
  и берёт первую, куда реально может писать (проверка настоящим файлом, а не
  наличием папки).
- **Прежние звуки переносятся автоматически** из `Documents\ForgePad` при первом
  запуске новой версии.
- **Если копирование всё-таки запрещено, звук подключается по ссылке** на исходный
  файл и продолжает играть. В каталоге он помечается как связанный.
- **Портативный режим:** пустой файл `portable.txt` рядом с `ForgePad.exe`
  переносит данные в папку `data` рядом с программой.
- Ошибки импорта по-прежнему показываются списком, без падения.

### Установка

1. Установи [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) и перезагрузи ПК.
2. Скачай `ForgePad.exe` из этого релиза и запусти.
3. В Discord выбери устройство ввода **Windows (VB-Audio Virtual Cable)**.
4. Перетащи звуки в окно и нажми плитку или её клавишу.

### Требования

- Windows 10/11 x64
- VB-Audio Virtual Cable
- .NET 10 Desktop Runtime

### Известные ограничения

- Задержка через кабель ~300–400 мс (буфер VB-Cable). В наушники — ~60 мс.
- Пока приложение работает, «микрофон по умолчанию» — кабель.
