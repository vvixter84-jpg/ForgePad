## ForgePad 1.0.1

Исправление падения при добавлении звуков.

### Что починили

- **Ошибка при загрузке mp3 больше не роняет приложение.** Импорт каждого файла
  обёрнут в обработку: если файл занят другой программой, лежит в защищённой папке
  или исчез, появится понятное сообщение со списком проблемных файлов, а остальные
  добавятся.
- **Любая ошибка в интерфейсе больше не закрывает программу.** Раньше исключение
  в обработчике кнопки давало системный диалог «неизвестное исключение» и завершало
  процесс — теперь показывается текст ошибки, а приложение продолжает работать.
- **Сбой в аудиопотоке не убивает процесс.** Один плохой блок отдаёт тишину, голоса
  сбрасываются, ошибка пишется в лог.
- **Декодирование переведено на Media Foundation** — это надёжнее для mp3, m4a и flac,
  чем старый ACM-путь NAudio. Если Media Foundation не справился, включается запасной
  декодер.
- **Лог пишется в несколько мест** (`%LOCALAPPDATA%\ForgePad\forgepad.log`, затем рядом
  с exe, затем во временную папку) — раньше при недоступной папке он терялся,
  и причину падения было не видно.

### Установка

1. Установи [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) и перезагрузи ПК.
2. Скачай `ForgePad.exe` из этого релиза и запусти.
3. В Discord выбери устройство ввода **Windows (VB-Audio Virtual Cable)**.
4. Перетащи звуки в окно и нажми плитку или её клавишу.

### Требования

- Windows 10/11 x64
- VB-Audio Virtual Cable
- .NET 10 Desktop Runtime

### Известные ограничения

- Задержка через кабель ~300–400 мс (буфер VB-Cable). В наушники — ~60 мс.
- Пока приложение работает, «микрофон по умолчанию» — кабель.
