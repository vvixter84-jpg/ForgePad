## ForgePad 1.0.0

Саундпад для Windows: звуки уходят в микрофон вместе с голосом, без переключения
устройства в Discord.

### Что внутри

- Дуплексное аудиоядро на WASAPI: гарнитура + пэды → виртуальный кабель и наушники.
- Перехват микрофона по умолчанию с возвратом при выходе и сторожевым процессом.
- Глобальные горячие клавиши с проверкой конфликтов.
- Каталог звуков с дедупликацией по хешу, имена отдельно от файлов.
- Настройка каждого звука: название, клавиша, громкость, цвет.
- 9 тем с переключением на лету.
- Монитор: слышишь пэды сам с задержкой ~60 мс.

### Установка

1. Установи [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) и перезагрузи ПК.
2. Скачай `ForgePad.exe` из этого релиза и запусти.
3. В Discord выбери устройство ввода **Windows (VB-Audio Virtual Cable)** — это пункт
   «системное по умолчанию».
4. Перетащи свои звуки в окно и нажми плитку или её клавишу.

### Требования

- Windows 10/11 x64
- VB-Audio Virtual Cable
- .NET 10 Desktop Runtime (если его нет — Windows предложит установить)

### Известные ограничения

- Задержка через кабель ~300–400 мс (буфер VB-Cable). В наушники — ~60 мс.
- Пока приложение работает, «микрофон по умолчанию» — кабель.
- Проверено на Windows 11 25H2.
